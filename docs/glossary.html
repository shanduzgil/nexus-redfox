NEXUS REDFOX Glossary

Shared terminology makes technical documentation and software analysis easier to understand.

Code Intelligence

Techniques and project information used to understand source-code structure, relationships and important project context.

Codebase Analysis

Systematic examination of a software project and its structure, components, relationships and dependencies.

Project Graph

A representation of relationships between project components or areas.

Source-Code Analysis

Analysis of source code to understand its structure, relationships and behavior.

Dependency Analysis

Inspection of how project dependencies participate in the software system.

Security Analysis

Security-focused investigation of authorized software to identify areas requiring closer review.

Local-First

An approach that prioritizes analysis and processing in the local environment rather than automatically sending project data to a remote service.
